# Logo

The logo represents multiple application connections converging at a shared proxy hub, then fanning out to destinations. It was generated with the built-in image generation tool and selected by the project owner on 2026-10-23.

- Source image: `AppProxyBridge.App/Assets/logo.png` (transparent PNG).
- Windows icon: `AppProxyBridge.App/Assets/app.ico` (16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel PNG frames).
- The application executable, window, tray and MSI shortcut use this icon.

## Generation prompt

```text
Use case: logo-brand.
Asset type: a single finished app logo/icon for App Proxy Bridge, a selective application proxy utility.
Primary request: depict MANY NODES CONVERGING INTO ONE CENTRAL NODE, THEN FAN OUT AGAIN. This topology is the essential visual concept. Read visually from LEFT TO RIGHT: exactly three small source nodes on the left, three smooth paths converge into ONE prominent central hub node, then three smooth paths diverge outward into exactly three small destination nodes on the right. Every path visibly meets the same central hub. It must read as many -> one -> many, NOT a branching tree, NOT a Y junction, NOT nodes connected around a ring. Make it a memorable compact brand symbol rather than a detailed network diagram.
Style: disciplined elegance of an original native iOS/macOS utility app icon. Clear silhouette, optical balance, very few shapes, generous breathing room, precise continuous curves. Rounded square endpoint nodes; the central hub is a slightly larger softly rounded square. Bold uniform strokes, smooth joins. Vertically symmetric and horizontally balanced composition. No arrows, labels or letters. Readable at 32 pixels.
Composition: 1024 x 1024 square. One centered continuous-curvature rounded-square app tile with a small transparent safety margin outside. Rich cobalt blue tile with a restrained smooth blue gradient. All six endpoint nodes, the central hub, and all connecting curves are porcelain white, forming one coherent high-contrast glyph. Central hub has a tiny restrained tonal highlight to suggest the shared gateway, not a different color. The full node glyph occupies about 65% of tile width. White paths converge gently; use a straight middle path and curved upper/lower paths on each side. Keep clear blue gaps between paths until they join the hub.
Materials: almost flat graphic design with only subtle native app-icon layering; matte clean surfaces, minimal soft shadow, no dramatic extrusion.
Constraints: Exactly ONE icon, no alternatives or presentation board. Background outside tile genuinely transparent; tile opaque. No text, no watermark, no devices, no UI screenshot, no mesh, no extra nodes, no globe, no shield, no lock, no bridge illustration, no ribbons, no lens effects, no heavy 3D, no shiny plastic, no decorative circuitry.
```
